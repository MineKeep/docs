# Public API

MineKeep offers a free, unauthenticated, read-only REST API at `https://api.minekeep.net`.

The interactive documentation (Swagger UI) lives at [api.minekeep.net/docs](https://api.minekeep.net/docs), and the raw OpenAPI 3.1 document at [api.minekeep.net/openapi.json](https://api.minekeep.net/openapi.json).
